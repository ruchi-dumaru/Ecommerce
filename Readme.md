# E-Commerce Website

A full-stack e-commerce website built using the MERN stack.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript
- React Router
- Context API

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Image Upload & Storage
- Cloudinary

### Admin Panel
- React.js
- Tailwind CSS
- Product management
- Add / Remove products
- Product listing
- Admin dashboard
